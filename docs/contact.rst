Getting help and contacting us
==============================

We want NiMARE to be usable, so please reach out if anything is unclear, broken, or missing.
There is no such thing as a question that is too small.

Every page of this documentation has a **Contact us** button in the bottom-right corner that links
to the options described below.

.. _contact-neurostars:

Ask a question on NeuroStars
----------------------------

`NeuroStars`_ is the best place for general, public questions about using NiMARE:
how to set up a meta-analysis, which estimator to use, why a result looks the way it does,
or what an error message means.

* Browse or post questions with the ``nimare`` tag: `NeuroStars NiMARE tag`_
* When posting, please use the `"Software Support" category with the "nimare" tag <NeuroStars software support_>`_
  so that the right people see it.

NiMARE developers follow NeuroStars, and answers there stay searchable for the next person with the
same question, which is why we prefer it over private email for usage questions.

To make it easy for us to help you, please include:

* the version of NiMARE you are using (``python -c "import nimare; print(nimare.__version__)"``),
* a minimal code snippet that reproduces the problem,
* the full traceback, if there is one.

.. _contact-email:

Email us
--------

For questions that do not fit a public forum, email us at neurosynthorg@gmail.com.

This address is best for:

* consulting, collaboration, or paid support inquiries,
* questions involving unpublished or otherwise sensitive data,
* anything else you would rather not discuss in public.

For general usage questions, `NeuroStars`_ will usually get you a faster answer.

.. _contact-chat:

Chat with the community
-----------------------

For informal conversation with NiMARE users and developers, join the
`NiMARE channel on the Brainhack Mattermost <https://mattermost.brainhack.org/brainhack/channels/nimare>`_.

.. _contact-bugs:

Report a bug or request a feature
---------------------------------

If you have found a bug, or would like to see a new feature, please open an issue on GitHub at
`github.com/neurostuff/NiMARE/issues <https://github.com/neurostuff/NiMARE/issues>`_.

If you would like to help fix it yourself, the :doc:`contributing` guide walks through the process.

.. _contact-security:

Report a code of conduct violation
----------------------------------

NiMARE follows a `code of conduct <https://github.com/neurostuff/NiMARE/blob/main/CODE_OF_CONDUCT.md>`_.
To report a violation, email us at neurosynthorg@gmail.com.
